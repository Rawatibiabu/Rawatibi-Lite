Rawatibi Lite — offline Android source project

Open this folder with Android Studio (JDK 17). Let Gradle sync, then Build > Build APK(s).
Output: app/build/outputs/apk/debug/app-debug.apk

No Firebase, cloud, internet permission, or external dependencies other than Android Gradle Plugin.
Supports 8 employees, manual salary additions, arrears, cash/bank payments, fingerprint prompt when supported, JSON backup import/export.

Important: This is SOURCE CODE, not a compiled APK. It has not been compiled/tested in this environment.
Backup files contain sensitive employee information in readable JSON; store them securely.
